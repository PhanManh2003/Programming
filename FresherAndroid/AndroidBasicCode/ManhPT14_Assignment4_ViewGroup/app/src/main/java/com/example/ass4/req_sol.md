# Requirement

Create an app to display a list of books
Objectives:
The objective of this exercise is to create an Android app using RecyclerView to display a
list of books. Each book will include a title, author, and an illustrative image.
Technical Requirements:
 Create a new Android project in Android Studio.
 Create a list of books (at least 10 books) in a mock data file (it can be an array or a
JSON file).
 Create a RecyclerView to display the list of books.
 Create a data model for the book with attributes such as title, author, and image
path.
 Create an Adapter to link the data from the list of books to the RecyclerView.
 Create a layout for each item in the list of books by creating a separate XML layout
file (e.g., book_item.xml) to display the information of each book.
 When the user clicks on a book in the list, display the detailed information of the
book in a new screen.
 Optionally, implement sorting the list of books by title or author.
 Ensure that your app runs smoothly and is user-friendly.
 (Optional) Add a search feature so that users can search for books by title or
author
